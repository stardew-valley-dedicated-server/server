# Related Projects & Links

## Stardew Valley

## Modding

- [SMAPI](https://smapi.io/): The modding framework that powers JunimoServer
- [SMAPI Mod Compatibility](https://smapi.io/mods): Which mods work with the current game version
- [SMAPI Log Parser](https://smapi.io/log): Makes SMAPI logs readable and shareable for bug reports
- [Modding Wiki](https://stardewvalleywiki.com/Modding:Index): Official modding documentation
- [Nexus Mods](https://www.nexusmods.com/stardewvalley): Largest mod repository
- [Stardew Valley Discord](https://discord.gg/stardewvalley): Community and modding help
